# ADR-0001 三仓库与最新实现

- 日期：2026-10-07
- 状态：active；依据当前用户要求

采用 workspace/hub/lab 三个独立 Git 仓库。workspace 忽略产品目录，manifest 记录地址和 main，不使用 submodule，不维护组合版本。需要复现测试时仅在当次报告记录双方 SHA。

单项目任务在子仓库进行，跨项目任务从工作区协调；显式读取目标 AGENTS。产品需求、架构、测试独立，标准原始资料统一到 workspace。协议解释和测试不能把双方同一实现错误当成标准。

用户事项单一正本位于 workspace 根，产品入口仅导航；产品独立 clone 不依赖父目录启动。共享标准可单独获取，运行时采用本地导入或许可允许的打包。

Agent 连续完成开发与验证；自审如实记录。main 通过 PR 和真实 CI 集成，禁止强推/删除，0 个强制外部审批，无永久绕过。初始化空 README 与基础资料同步后接通 CI 再保护；不改写 Lab 既有历史。

本决定改变仓库组织和协作方式，不降低两款产品完整功能范围，不自动决定许可证或依赖最终版本，也不自动授权未来远端发布。
