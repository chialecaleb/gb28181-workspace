# 联调环境约定

当前两款应用尚未实现，本页为环境合同，不是已可运行的 Docker Compose 或启动说明。2026-10-07 已为 Lab M0 准备本机第三方测试平台配置和连通性检查；TCP 可连接不等于 Lab/Hub 或 SIP 互通已经通过。

## 拓扑与身份

最小场景为一个 Hub 平台、一个 Lab 虚拟 IPC、一个通道和一份合法合成媒体。扩展 NVR、多平台、级联、国密和故障前先通过最小场景。平台、设备、通道 ID 均为 20 位字符串，平台域、认证域、传输、Contact 和实际监听地址分别配置。

本地初始端口预算：Hub SIP 5060，Lab 设备 SIP 15061、内置平台 SIP 15062；Hub HTTP 18080，Lab HTTP 18081，前端开发 5173；Hub RTP 池 30000—30999，Lab 媒体池 31000—31999。Lab 调整避开第三方测试端口，具体测试目标只放其本地配置。均为开发建议，非标准强制值或已实现应用接口。启动前检查占用、UDP/TCP、NAT 映射、地址族及主动/被动媒体方向；冲突时明确修改，不自动结束他人进程。

凭据、设备地址、证书与密钥只放忽略的 .local 或 .env.local。示例使用合成身份，不复制生产配置。预留端口不是开放防火墙授权，接入真实网络须在用户授权范围内。

本轮真实配置唯一存于 Lab 根 .env.local，参考索引与图也保存在 Lab 忽略目录，工作区不复制第二份凭据。Lab 已提供 local_env.py 准备检查，加载优先级为进程环境 > .env.local > .env；应用加载器仍待实现，具体合同由 [Lab 环境说明](https://github.com/chialecaleb/gb28181-lab/blob/main/docs/dev-rules/local-test-environment.md)维护。新说明当前在本地准备分支，待有效授权后远端同步。

用户指定第三方代码与接口文档只能在测试阶段用于查找测试接口，禁止开发参考。先独立实现/验证，再以一个合成设备/通道、零媒体、最长 10 分钟进行受控本地测试。Web 密码不推断为 SIP 密码；认证方式/realm 等在测试阶段只读发现，结果、原字节与清理独立记录。当前不要求用户启动不存在的 Lab 应用，事项见 [WS-ACT-002](../../USER-ACTIONS.md#ws-act-002)。

## 时间、数据与恢复

记录系统/业务时间、时区、时钟偏差、随机 seed、媒体 hash、码率/分辨率/帧率、网络故障注入参数。SIP 与安全认证的有效期按原文核对，不能通过关闭时间校验绕过失败。

每次运行使用独立实验数据目录；结束时停止会话、释放端口/句柄、恢复故障注入并清理本次资源，保留脱敏证据。真实录像与设备数据不自动删除。双方未来发布包各自管理存储，不共享业务数据库或私有控制 API。
