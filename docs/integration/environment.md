# 联调环境约定

当前两款应用尚未实现，本页为环境合同，不是已可运行的 Docker Compose 或启动说明。

## 拓扑与身份

最小场景为一个 Hub 平台、一个 Lab 虚拟 IPC、一个通道和一份合法合成媒体。扩展 NVR、多平台、级联、国密和故障前先通过最小场景。平台、设备、通道 ID 均为 20 位字符串，平台域、认证域、传输、Contact 和实际监听地址分别配置。

本地初始端口预算：Hub SIP 5060，Lab SIP 从 15060 起；Hub HTTP 18080，Lab HTTP 18081；Hub RTP 池 30000—30999，Lab 媒体池 31000—31999。均为开发建议，非标准强制值或当前应用配置键。启动前检查占用、UDP/TCP、NAT 映射、地址族及主动/被动媒体方向；冲突时明确修改，不自动结束他人进程。

凭据、设备地址、证书与密钥只放忽略的 .local 或 .env.local。示例使用合成身份，不复制生产配置。预留端口不是开放防火墙授权，接入真实网络须在用户授权范围内。

## 时间、数据与恢复

记录系统/业务时间、时区、时钟偏差、随机 seed、媒体 hash、码率/分辨率/帧率、网络故障注入参数。SIP 与安全认证的有效期按原文核对，不能通过关闭时间校验绕过失败。

每次运行使用独立实验数据目录；结束时停止会话、释放端口/句柄、恢复故障注入并清理本次资源，保留脱敏证据。真实录像与设备数据不自动删除。双方未来发布包各自管理存储，不共享业务数据库或私有控制 API。
