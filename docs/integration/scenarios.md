# 联调场景目录

所有场景当前为 not-run，应用尚未实现。下面是验收设计，不是自动测试已存在。

| ID | 场景 | 必要断言与失败路径 |
| --- | --- | --- |
| INT-001 | REGISTER/认证/续期/注销 | 身份、鉴权、有效期与最终绑定；错密码、过期、重复请求 |
| INT-002 | 心跳与离线 | 观测时间、丢失阈值和重连；乱序、断链、恢复，无永久僵尸设备 |
| INT-003 | Catalog/DeviceInfo/状态 | SN、DeviceID、分页/多响应、条目计数；超时、重复与错误身份 |
| INT-004 | INVITE/ACK/BYE 实时媒体 | SDP、SSRC、角色、实际解码；SIP 成功但无流、早停、迟到包 |
| INT-005 | UDP/TCP 主动/被动媒体 | 协商与真实传输一致；NAT、半包、断线、重连与端口回收 |
| INT-006 | PTZ/预置位/控制 | 权限、响应、实际图像或状态变化；非法参数与占用冲突 |
| INT-007 | 报警/订阅/通知 | 订阅有效期、Notify 身份与次序；过期、重复、取消和恢复 |
| INT-008 | 录像检索/回放/下载 | 时间范围、真实媒体、进度、取消、校验与清理 |
| INT-009 | 平台级联与语音 | 逐跳身份、资源共享范围、实际音频与释放；循环与失联 |
| INT-010 | GB35114 A/B/C | 认证、签名、加密、独立向量；篡改、吊销、重放与轮换失败 |
| INT-011 | 重启、MQ 中断、所有权转移 | 命令幂等、旧代次拒绝、有界日志、恢复、状态一致 |
| INT-012 | 容量与长期稳定 | 独立 UA/通道/媒体分别计数，固定硬件与码流，记录 CPU/内存/句柄及结束清理 |

每个场景细化到产品需求 ID、标准页、前置配置、输入报文、预期转换和独立证据后才能标为有测试覆盖。完整产品范围仍以双方需求正本为准，本表不缩减适用条款。
