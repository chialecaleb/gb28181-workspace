## 资料管理与迁移记录

2026-10-07 从 Lab 迁入两套原始 PDF、OCR 与全部图片，逐文件 SHA-256 校验前后相同。Hub 的两份 PDF 与集中副本相同；其早期缺图 OCR 不作为第二份标准正本，原始文件保留于本次本地迁移备份。上文历次阅读和视觉核对为既有记录，本次仅核验文件完整性，没有重新审查条文或声称标准状态已重新查证。

[sources.json](sources.json)登记当前原始资源的大小与 SHA-256。`python scripts/check_sources.py` 验证清单、资源存在性与字节完整性；标准内容变更必须核对来源并显式更新清单，不自动把新文件当作已审核资料。

共享资料不承担 Agent 指令。产品需求、实现和互通判断不能直接由 OCR 推导；摘录应标明版本、条款、印刷页、PDF 页、角色、方向与核对状态。LAB 编号是已有定位映射，Hub 的对应关系在其产品文档中维护。

开发者可读取工作区资料，或从本仓库独立获取所需文件并核对哈希。产品构建和单元测试不应依赖兄弟仓库；运行时原文展示采用本地资料导入或经许可打包，不临时请求 GitHub。标准版本固定到适用规范，不能因为代码跟随 main 就自动替换有日期的标准引用。资料随产品分发前的许可确认见[用户事项](../../USER-ACTIONS.md#ws-q-002)。
